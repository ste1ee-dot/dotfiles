# Dotfiles

### Requirements

* **Terminal:** `kitty`
* **File Manager:** `nautilus`
* **Application Launcher:** `rofi`
* **Web Browser:** `firefox`
* **Audio Processing:** `easyeffects`
* **Desktop Shell:** `quickshell`
* **Wallpaper Manager:** `hyprpaper`
* **Core Portal Framework:** `xdg-desktop-portal`
* **Hyprland Portal Backend:** `xdg-desktop-portal-hyprland`
* **GTK Portal Backend:** `xdg-desktop-portal-gtk`
* **GNOME Portal Backend:** `xdg-desktop-portal-gnome`
* **Audio Session Manager:** `wireplumber`
* **Clipboard Manager:** `wl-clipboard`
* **Media Controller:** `playerctl`
* **Brightness Controller:** `brightnessctl`
* **Screenshot Tool:** `hyprshot` (requires `grim` and `slurp`)
